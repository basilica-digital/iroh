How to use

  1. Build with: wasm-pack build --target web iroh/examples/webrtc-browser
  2. Serve this directory: python3 -m http.server 8080 -d iroh/examples/webrtc-browser
  3. Open two browser tabs pointing to http://localhost:8080
  4. Click "Initialize" in both tabs and wait for "Online!"
  5. Copy the address from Tab A and paste it into Tab B's "Peer Address" field (and vice versa)
  6. Type a message and click "Send" — it will be echoed back
