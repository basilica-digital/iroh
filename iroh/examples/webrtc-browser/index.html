How to use

  1. Install Trunk: cargo install trunk
  2. From this directory: trunk serve
  3. Open two browser tabs at http://127.0.0.1:8080
  4. Click "Initialize" in both tabs and wait for "Online!"
  5. Copy the address from Tab A and paste into Tab B's "Peer Address" (and vice versa)
  6. Type a message and click "Send" — it will be echoed back
